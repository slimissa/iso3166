## The three bugs this release exposed

v1.10.0 shipped after three CI failures that the previous releases'
tooling did not catch. Each is logged for v1.10.1:

1. `cargo clippy -- -D warnings` is stricter than `cargo test`.
   Test 35 in `test-derived-queries.sh` must run clippy, or future
   bundles will continue to pass locally and fail in CI.
2. `check_docs_match_tree.py` is in CI only, not the release gate.
   Rule 26 (the gate checks every derived artifact) was not applied
   to this check. v1.10.1: add it to release.sh's gate.
3. `set -euo pipefail` + `if ! cmd | grep` is a SIGPIPE trap: grep
   exits on match, the upstream command gets SIGPIPE, pipefail
   propagates the failure, `!` inverts, `die` runs. The --force
   resume check hit this. Fix: `grep ... <(cmd)` (process
   substitution). A rule should be added to RELEASE_PATTERN.md.
