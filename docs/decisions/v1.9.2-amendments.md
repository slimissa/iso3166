# v1.9.2 — Amendments to the v1.0.0 decisions

This is a record, not a new decision. It documents where the tree no
longer matches the text of `v1.0.0-decisions.md`. D2, D3, D5 and D7 are
not edited; this file says what the tree now holds and where that is
verified. Releases are named only where the repository records them.

---

## D2 — Coverage

**Text in v1.0.0.** Approximate counts: 249 officially-assigned, ~13
exceptionally-reserved, ~4 user-assigned, ~30 withdrawn.

**Tree now.** 249 officially-assigned, 2 exceptionally-reserved, 1
user-assigned, 25 withdrawn (252 active, 277 total). Source:
`docs/STATE.md`, checked by `tools/check_state_doc.py`.

**Release.** None: D2 gave approximate counts and was never amended.
The approximations were never reconciled with the final population.

**Superseded decision.** None.

---

## D3 — Data model

**Text in v1.0.0.** "Twelve fields per active entry, plus three for
withdrawn."

**Tree now.** One shared field set of 19 properties (`commonFields` in
`schema.json`); every active and withdrawn entry in `iso3166.json`
carries the same 19 keys.

**Release.** Not determinable from the tree: the repository has no
decision log entry for the change and the CHANGELOG records fields
being added one at a time.

**Superseded decision.** None.

---

## D5 — Cross-registry validation via committed snapshots

**Text in v1.0.0.** The snapshot check is advisory (warn, not fail) in
v1.0.0 and becomes blocking in v1.0.1.

**Tree now.** Blocking. `docs/PROVENANCE.md` records that, as of v1.0.1,
`tools/validate.py` treats a missing snapshot as a FAIL.

**Release.** v1.0.1.

**Note.** This is D5 executed as written, not an amendment.

---

## D7 — Versioning: single source, all references agree

**Text in v1.0.0.** Five references must agree: `VERSION`, the
CHANGELOG top heading, the README badge, `meta.version`, and the Parquet
footer. Wrapper package versions are "independent".

**Tree now.** `tools/check_version_consistency.py` also requires the
wrapper versions to agree: `wrappers/python/pyproject.toml`,
`wrappers/python/iso3166/__init__.py`, `wrappers/javascript/package.json`,
`wrappers/rust/Cargo.toml` and `wrappers/rust/Cargo.lock`. The README
badge is optional. The README and `release.sh` count these as eight
version sites (`Cargo.toml` and `Cargo.lock` as one, the optional badge
not counted).

**Release.** By v1.5.0, whose CHANGELOG entry records the version bump
"across the eight version sites".

**Superseded decision.** D7's statement that wrapper versions are
independent.
