## What this release proves

v1.12.0 is the final capability release. It replaces the last
heuristics in the registry (the `is_eu`/`is_eea`/`is_eurozone`
hardcoded lists) with date-scoped membership arrays. The registry now
knows when a country joined or left a club, not just whether it is a
member today.

The `is_eu`/`is_eea`/`is_eurozone` queries remain as current-status
aliases. A consumer who needs the historical answer uses
`is_eu_member_at` and its siblings.

## The completed temporal identity layer

- introduced: when the code was born.
- is_active_on: whether the code existed on a date.
- currency_at: the currency (lifetime-bounded).
- is_eu_member_at / is_eea_member_at / is_eurozone_member_at /
  is_in_customs_union_at: club membership on a date.

Every query returns a defensible answer: either a value derived from
a documented source, or `False` (for binary queries) / `None` (for
the tri-state queries). The registry does not guess.

## What's next

The capability phase is complete. The remaining releases are
conditional (sanctions), nice-to-have (geography), documentation
(ecosystem), or a new companion registry (subdivisions). The schema
is stable for the foreseeable future.
