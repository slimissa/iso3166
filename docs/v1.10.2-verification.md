## What this release proves

v1.10.2 is the *second* release in the series to ship on the first
`release.sh` attempt. v1.10.0 took six; v1.10.1 and v1.10.2 took one
each. The `gh run list` retry loop was exercised *live* during the
release: the first query returned empty, the 30-second sleep was
enough, the second query succeeded. Rule 28 (added in this release)
was *tested by being used*.

## The three things v1.10.2 actually defined

1. `--raw` is now *defined per command*, not just aligned:
   - `successors`, `region-tree`, etc. → `alpha_2`
   - `validate` → `code`
   - `info` → usage error (no default)
   This is *more* careful than a one-size-fits-all default. The CLI
   *teaches* with its error message (lists all 19 valid fields).

2. CONTRIBUTING.md's Release prerequisites now lists bash, node, go,
   cargo, gh, python3, rustup. The gate's cross-language check
   runs node/go/cargo, so the prerequisites reflect what the *gate*
   needs, not just what release.sh's *direct* invocations need.

3. Rule 28's wait loop was used *during this release* and worked.
   The rule is now tested in production, not just in a synthetic test.
