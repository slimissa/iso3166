## What this release proves

v1.11.0 is the first data-enrichment release. It proves that the
registry can carry a field whose source is *outside* the ISO OBP
harvest: Wikipedia's Changes table, with an explicit quarantine list
for the 27 codes whose assignment date is contradictory or unknown.

It also proves the `--force` path works in production: the release
was interrupted by a CI failure (version-string drift in PROVENANCE.md
and CONTRIBUTING.md), fixed with a manual edit, and resumed with
`--force` without a double-tag or a double-commit.

## The tri-state model

`is_active_on` returns `True`, `False`, or `None`. `None` is not a
failure — it's the honest answer when the source is silent. This is
the pattern the rest of the ecosystem should follow for any field
whose source can be incomplete.
